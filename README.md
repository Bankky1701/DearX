# Bacarrathack - เว็บสูตรบาคาร่า SA Game (React + TypeScript)

ระบบสูตรบาคาร่า AI คำนวณเค้าไพ่แบบเรียลไทม์ พร้อมหน้าล็อบบี้ 16 โต๊ะ, ตารางเค้าไพ่หลัก (Bead Plate Road 72 ช่อง), กราฟสถิติแนวโน้มคะแนน, ระบบเติมเครดิตด้วย Redeem Code, และระบบจัดการหลังบ้าน (Admin Panel)

## ฟังก์ชันการใช้งาน
- **เข้าสู่ระบบ / สมัครสมาชิก**:
  - รองรับบัญชีทดลอง:
    - แอดมิน: `admin` / `1234` (สิทธิ์แอดมิน เข้าหลังบ้านได้)
    - สมาชิก: `member` / `1234`
  - สมัครสมาชิกใหม่ รับเครดิตทดลองฟรีทันที 50 เครดิต
- **ห้องบาคาร่า (16 โต๊ะ)**:
  - สรุปอัตราการชนะ (Win Rate %) ของแต่ละห้อง
  - สถานะการเปิดไพ่ของดีลเลอร์สด
- **หน้าสูตรและการคำนวณ (Formula)**:
  - คำนวณอัตราการชนะและเค้าไพ่ 5 ตาล่าสุด
  - แนะนำตาถัดไปแทง: **เจ้ามือ (Banker)**, **ผู้เล่น (Player)**, หรือ **รอสูตร (Wait)**
  - ตารางเค้าไพ่ลูกปัด Bead Plate Road 72 ช่อง (12 แถวแนวตั้ง x 6 แถว)
  - เพิ่มเค้าไพ่ด้วยตนเอง (Manual Input) หรือเปิดระบบบอทจำลองสดอัตโนมัติ
  - ตารางสรุปผลแพ้/ชนะ และจำนวนไม้ที่ใช้
  - กราฟเส้นแสดงแนวโน้มคะแนนสะสม (Score Trajectory)
  - เปลี่ยนชุดสูตร (สูตรชุดที่ 1, สูตรชุดที่ 2)
- **ระบบเติมเครดิต (Redeem Code)**:
  - โค้ดฟรีสำหรับทดสอบ: `VIP999`, `BACC888`, `FREE50`, `LUCKY777`
  - ตรวจสอบสถานะการใช้งานโค้ด ป้องกันการใช้ซ้ำ
- **ระบบจัดการหลังบ้าน (Admin Dashboard)**:
  - แดชบอร์ดสรุปยอดสถิติ, ผู้ใช้ออนไลน์, จำนวนสูตรที่เข้า
  - จัดการผู้ใช้งาน (ดูรายการ, แก้ไขรหัสผ่าน, ปรับยอดเครดิต)
  - จัดการสูตร AI (ดูแพทเทิร์นสูตร, จดสูตรใหม่ 5 ตา = ผลลัพธ์, เพิ่มชุดสูตร)
  - ระบบสร้าง Redeem Code อัตโนมัติ (ระบุยอดเครดิตและจำนวน พร้อมปุ่มคัดลอก)
